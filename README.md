# 台東好吃｜美食口袋地圖

用地圖尋找臺東市中心的早午餐、餐廳、咖啡與甜點，收藏下次想去的店。

Instagram：https://www.instagram.com/taitung_delicious/

網站標題、首頁品牌、WebSite結構化資料與社群連結使用「台東好吃」。建置會把正式店家資料直接產生在首頁HTML，並更新robots.txt與sitemap.xml；只收錄正式首頁，不提交研究檔、JSON或篩選狀態。搜尋收錄、排名及Search Console驗證需另行確認，建置成功不代表已被Google收錄。

網站：https://taitung.adventurehotairballoon.com/

## 使用

「幫我選午餐」可輸入「午餐簡單吃，100元內，1小時結束，不用等太久」，辨識常見條件，再手動修改。預設每人100元、騎機車、從出發到吃完60分鐘，最多列3間有官方/政府主餐價格依據的候選。未知或矛盾語句先提示，價格未知不當符合。候餐、停車、車程與用餐時間未確認，不保證一小時內完成；定位只顯示直線距離。這是免費的常見語句辨識，未串接AI模型。切回「自己找店」保留原瀏覽條件。

分類、關鍵字、現在或指定時間、收藏與去過標記可組合篩選。地圖與清單同步；手機可切換清單與地圖。按「我的位置」才請求定位，距離為直線距離，拒絕定位仍可使用清單。

收藏、去過與備註只保存在目前瀏覽器，不上傳、不跨裝置同步。「備份與說明」可以匯出及匯入JSON。從其他網址搬過來時，先在原站匯出，再到新站匯入；清除網站資料會失去收藏。

營業狀態按收錄時段推算，不保證臨時店休、座位或最後點餐時間。來源衝突及時間未知的店不會通過營業中篩選。照片請查看店家官方資訊或Google Maps，本專案不複製他人照片。

## 內容維護

`content/shops/*.md` 是正式來源，每間店一份Markdown。資料欄位與來源放在JSON格式的front matter，介紹放在內文。`content/catalog.json` 是收錄索引。格式詳見content/README.md。

```sh
npm run build
npm test
```

建置免安裝相依套件，需要Node.js22以上；網站本身為HTML/CSS/JavaScript與本地Leaflet靜態資源。建置產生dist/shops.json，不要直接維護產生的JSON。

本機預覽可用 `python -m http.server 8765 --bind 127.0.0.1 --directory dist`。GitHub Actions在main更新時驗證並發布dist至GitHub Pages；PR只驗證。

## 自動研究與審核

擁有者另以本機Codex每週有界研究，候選、否決紀錄與核准版本保存在非公開research目錄。待審上限3筆，每輪最多20分鐘與15來源頁，另輪替查核3間舊店。這個排程需要擁有者電腦與Codex開啟、可以連網。

研究完成不等於發布。擁有者在對話核准確切內容後，才將對應版本放進正式Markdown。main中的內容皆應先審核，修改後重新核准；GitHub不會自行找資料。

發布工具先驗證核准版本、備份、建置並測試，再以明確允許清單準備公開目錄。research、登入憑證、node_modules與runtime不公開；HTTPS資料與核准內容相符才標記published。部署失敗保留核准紀錄供核對及重試。

## 範圍與來源

鐵花周邊約3公里的精選清單，不是完整店家資料庫。優先使用可讀官方店家或政府來源，逐店顯示查核日期；可讀資料不代表已電話或實地查核。價格未確認就留空。地圖底圖來自OpenStreetMap，保留來源標示；本專案不做圖磚預抓或離線下載。
